# 原版研究与本版取舍

研究对象为 [yugh6/Naiwa](https://github.com/yugh6/Naiwa)，固定版本 `553afb87508d3b05cda3af935616ed00e94dd3e4`，原版标注 v1.2.2。本项目独立实现兼容程序，保留素材格式和值得延续的交互体验。

## 原版值得保留的地方

原版使用真实图片与视频拆帧，避免重画角色造成质感变化。眨眼只改变眼部，身体保持稳定；笑声与完整大笑动作组合起来有辨识度。拖动采用平滑倾斜、松手采用衰减回弹，幅度克制。原版还考虑了单实例、全屏隐藏、笑倒停留和资源释放，这些都直接影响长期使用体验。

## 实际限制与改进

| 观察到的限制 | 本版处理 |
| --- | --- |
| 原版视线只在悬停身体时从 look=0 过渡到 look=1，不读取身体外的二维方向 | 读取全局鼠标位置，连续计算二维视线；移入身体后回正 |
| 直接放大转眼幅度容易改变眼形，破坏质感 | 只在原眼内小范围移动原纹理，并平滑限幅；动作期间使用原帧 |
| 下载仓库源码和下载可运行程序容易混淆 | 单独提供已编译的 Release、校验文件、安装脚本和固定入口清单 |
| 原图、音效及源码的授权边界没有统一许可证 | 独立编写 MIT 程序，原素材从作者仓库获取，避免混合标注 |
| 后续修改集中在单个大源码文件，不便定位 | 拆分动画、绘制、素材、窗口、设置和测试，中文列出修改入口 |

## 实现细节

眼神跟随使用指数缓动；拖动倾斜使用带阻尼的弹簧；戳肚子使用衰减振荡及双线性采样。动作按时钟选帧，静止画面不重复上传，稳定待机时减少定时器唤醒。

不能把源码中的定时器间隔当成屏幕真实刷新率。本版定时器最短 16 ms，大笑素材仍按其 30 fps 时间轴选帧；没有宣称把原动作变成原生 60 帧视频。

## 当前仍有限制

- 眼球变化幅度小，适合保留原图；并非三维眼球或大角度环视。
- 没有增加走路、吃饭等缺乏统一原版素材的动作，避免风格突变。
- 外部素材包不是本项目开源授权的一部分。
- 窗口缩放沿用原版素材的小尺寸画布，大幅放大会显得柔和。
- 当前发布程序未进行代码签名。

完整测试结果会记录在发布说明中；本文件描述设计和边界，不把尚未执行的测试写成已通过。
