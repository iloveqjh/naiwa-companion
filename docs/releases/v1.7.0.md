# 奶蛙陪伴 v1.7.0 · 文件口袋与桌面工具

把文件拖到奶蛙身上，选择暂存或转换；右键打开口袋，就能看到目录里的实际内容。本次公开版同时包含之前的小待办、说话气泡、文字收藏和转换核查修复。

## 新增与改进

- **文件口袋**：支持文件和文件夹，复制暂存、同名另存、逐文件 SHA-256 校验和取消操作；原文件保留，关闭窗口不删除内容。可刷新目录、打开文件夹、定位项目及转换所选文件。
- **小待办**：Enter 添加、勾选完成、双击修改、单步撤销，支持本机保存及窗口恢复。
- **说话气泡**：80 句原创文字、互动回应、待办汇报、提醒设置和安静时段。
- **文字收藏**：搜索、编辑、复制及主动收藏剪贴板文字，不在后台监听剪贴板。
- **文件转换**：36 种输入扩展名、223 种明确组合；校验结果后另存。修复照片方向、XLS 超限截断、隐藏表导出与异常 CSV 引号处理。
- **可选存储目录**：通过 `storage.local.json` 指定数据、口袋与默认输出目录，包含 D 盘配置示例。
- 保留原有眼神、按头回弹、拖动、动作原声、主题与全屏隐藏行为；补齐中文图文指南。

## 下载与使用

1. 下载本页附件 `NaiwaCompanion-Windows-v1.7.0.zip`，完整解压，运行 `NaiwaCompanion.exe`。
2. 没有素材时按窗口提示从原作者项目获取，已有用户保留自己的素材与主题。
3. 升级前退出旧版；替换程序与文档，保留原素材、主题和自己的 `storage.local.json`。未配置存储目录时使用原有应用数据目录。
4. 需要校验下载时，对照本页 `SHA256SUMS-v1.7.0.txt`。不要将 GitHub 自动生成的 Source code ZIP 当作可运行安装包。

桌宠与基础工具无需额外运行时。**办公转换需对应的 Microsoft Office；音视频及部分图片需 FFmpeg；PDF 处理需 Poppler。公开包不捆绑这些组件**，在「文件转换 → 转换工具」中配置。详见 [工具配置](https://github.com/iloveqjh/naiwa-companion/blob/main/docs/转换工具配置.md) 和 [支持范围](https://github.com/iloveqjh/naiwa-companion/blob/main/docs/格式支持与验证.md)。

扫描 PDF 没有 OCR，PDF 不直接转 Excel/PPT，动画 WebP 暂不支持，CSV 不保留公式与样式。样本检查通过不代表任意复杂文件都能成功，请检查结果是否符合用途。
