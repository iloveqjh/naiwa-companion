# 奶蛙陪伴 v1.7.1 · 文件拖入独立开关

右键奶蛙或托盘，勾选或取消「允许拖文件到奶蛙」。**默认开启，可以随时关闭，重启后记住选择。**

- 关闭后，拖文件到奶蛙身体不再弹出处理窗口；未处理的选择窗口会关闭。
- 重新勾选立即恢复，无需重启程序。
- 手动打开文件口袋、添加文件和使用转换器仍可用，已暂存文件保留。
- 从没有这个开关的旧版本升级，默认保持开启。

![右键菜单的文件拖入开关，演示环境](https://raw.githubusercontent.com/iloveqjh/naiwa-companion/main/docs/images/v1.7.1-switch.png)

下载 `NaiwaCompanion-Windows-v1.7.1.zip` 并完整解压；升级前退出旧版，保留自己的素材、主题、存储配置和数据。对照 `SHA256SUMS-v1.7.1.txt` 可校验下载包。

其余功能和转换工具要求沿用 1.7.0，见 [图文首页](https://github.com/iloveqjh/naiwa-companion)、[文件口袋](https://github.com/iloveqjh/naiwa-companion/blob/main/docs/文件口袋.md) 与 [转换工具配置](https://github.com/iloveqjh/naiwa-companion/blob/main/docs/转换工具配置.md)。
