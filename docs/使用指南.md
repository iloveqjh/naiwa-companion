# 使用指南

## 安装与启动

下载 [Windows 发布包](https://github.com/iloveqjh/naiwa-companion/releases/latest)，完整解压后双击 `NaiwaCompanion.exe`。程序会出现在鼠标所在屏幕的右下角。适用于 Windows 10/11 的 .NET Framework 4.x 环境，不需要安装 Python、Node.js 或提供模型密钥。

程序没有安装器，也不会添加开机启动。移动安装位置时，先退出奶蛙，再将整个文件夹移动过去。

## 使用原版素材

原版素材由 [yugh6/Naiwa](https://github.com/yugh6/Naiwa) 提供。需要两个文件：`素材.nwp`、`原版笑声.wav`。

- 放在 `NaiwaCompanion.exe` 旁边，下次启动会自动识别。
- 直接在右键菜单选择「下载原版素材」→「下载并使用」。首次下载约 26 MB，校验后自动切换，不需要运行脚本。
- 已经安装过原版：右键奶蛙 →「导入原版素材」→ 选择原来的文件夹。程序引用该文件夹，不移动或改写原素材。
- 也可运行 `scripts/Get-OriginalAssets.ps1` 下载固定版本，文件会进行 SHA-256 校验。

外部素材没有就绪或损坏时，会打开素材准备窗口，选择下载或本机已有素材。准备完成后显示真实的立体角色素材。

## 多主题和新动作

主题包放入程序旁边 `themes/主题名/theme.nct` 后，从右键「切换主题」选择。右键「选择动作」播放不同动作；双击重复当前动作。「循环当前动作」可让它播放后短暂停留再继续，手动停止、拖动或全屏隐藏会中断。

待机时保留眼神跟随和肚腹互动；播放动作时使用原帧的表情。经典主题仍保留原版大笑。主题包的准备方法见 [主题与动作](主题与动作.md)。

## 眼神交互

默认开启「身外跟随，身上回正」。奶蛙在待机时感知桌面鼠标位置，上下左右轻微转动眼内纹理，动作有缓动；鼠标进入可见身体区域后，缓缓回正。移动幅度很小，避免眼珠穿帮或破坏原图轮廓。

透明背景不算身体。眨眼、大笑、笑倒休息时优先保留动作画面。右键可以关闭跟随，恢复安静待机。

## 动作和声音

单击肚子会出现局部回弹，脸部和脚部保持稳定。单击其他位置不会戳肚子。双击会播放完整大笑，大笑中再次双击不会重叠；拖动或右键「停止大笑」可中断。笑倒后会一直躺着，单击站起来，双击可再笑一次。

声音默认关闭。勾选「原版笑声」后，从下一次大笑开始播放；播放中关闭立即停止声音。内置演示形象没有原版音频。

## 找不到奶蛙

1. 再次双击程序，奶蛙会回到鼠标所在屏幕右下角。
2. 看看托盘隐藏图标区域，双击奶蛙图标也能召回。
3. 检查是否处在全屏游戏或视频中。退出全屏后恢复，也可在托盘菜单取消「全屏时自动隐藏」。

普通窗口最大化不会被当成全屏。隐藏时不播放笑声；恢复后保留之前的笑倒姿势。

## 设置、卸载与问题记录

设置保存在 `%LOCALAPPDATA%\NaiwaCompanion\settings.json`。原版的设置文件不会被修改。错误提示及简要错误记录位于同一目录的 `error.log`。

退出奶蛙后，删除自己选择的安装文件夹和桌面快捷方式即可卸载。若要彻底清除设置，可另外删除上述设置目录。

程序尚未进行代码签名。遇到系统或安全软件提示时，可先检查发布来源、校验值和源码，根据自己电脑的管理要求处理；无须关闭防护或更改系统安全设置。
