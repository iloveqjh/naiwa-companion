# 验证记录

验证日期：2026-10-21。环境：Windows，本机 .NET Framework 4.x 编译器。

## 1.4.0

- 经典、离线、太极、天使、爬爬五种模式全部自测通过。
- 在 50%、85%、110%、150% 下检查全部四条窗口边缘，覆盖最大按压、回弹拉长及正负 6.5 度拖动倾斜。
- 所有录屏动作帧解码并渲染，仍保持最多 16 帧图像缓存；按头与肚腹命中坐标补偿透明留白。
- 核验反应使用完整动作时长、结束恢复待机、菜单动作不被改变，动作 WAV 和按头 WAV 能独立加载。
- 爬爬重新从原手机帧中排除出画步态；导出爬爬和天使 60 fps 带原声预览。

- 经典、太极、天使、爬爬均使用对应源帧，不再运行额头覆盖式眼睑代码。
- 检查反应片段实际有帧变化、结束后原样回到待机、原缓存像素未被修改、透明画布角落保持透明。
- 导出四主题 60 fps 实际渲染并逐段检查，爬爬回头使用与待机相同的起始帧和固定中心/脚底基准。

## 1.3.0

- 经典、无素材、太极、天使、爬爬五种模式通过按头相关和原有行为检查。
- 验证按住时压缩受限、松手连续、不拉回原姿势跳帧、拉长回弹和二次回摆、30/60/120 Hz 近似一致、反复按压连续、全屏中断无残留。

- 所有主题验证脚底锚定、压缩高度与透明画布边缘，眼睑只改变校准区域且保持原透明度。
- 以实际渲染器导出 60 fps 动作预览，检查压扁、回弹、回摆与半眯眼抬眼表情。

## 1.2.0

- 经典素材、无素材测试、太极、天使、爬爬五种模式均通过 `--self-test`。
- 三套本机主题共 1,441 张动作帧全部解码并渲染；保持最多 16 帧解码缓存。
- 新增验证：60 Hz 小数位移不丢步、暂停位置和步态、双侧边界折返、负坐标显示器、连续 30,000 步不出工作区、小屏幕约束、拖动后重置、镜像步态、颜色校准和透明边缘保护。
- 本机 65% 尺寸逐帧渲染约 8～10 ms/帧；这是测试环境数据，不代表所有电脑的帧率。
- 生成并检查实际渲染的太极起势、天使翅膀与爬行动作预览。个人录屏预览留在本机；公开首页使用另行生成并标注的主题插画。
