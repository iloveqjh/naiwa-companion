# 验证记录

验证日期：2026-10-21。环境：Windows，本机 .NET Framework 4.x 编译器。

## 1.2.0

- 经典素材、无素材测试、太极、天使、爬爬五种模式均通过 `--self-test`。
- 三套本机主题共 1,441 张动作帧全部解码并渲染；保持最多 16 帧解码缓存。
- 新增验证：60 Hz 小数位移不丢步、暂停位置和步态、双侧边界折返、负坐标显示器、连续 30,000 步不出工作区、小屏幕约束、拖动后重置、镜像步态、颜色校准和透明边缘保护。
- 本机 65% 尺寸逐帧渲染约 8～10 ms/帧；这是测试环境数据，不代表所有电脑的帧率。
- 生成并检查实际渲染的太极起势、天使翅膀与爬行动作预览。个人录屏预览留在本机；公开首页使用另行生成并标注的主题插画。
