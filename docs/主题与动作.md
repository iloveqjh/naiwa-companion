# 主题与动作

## 切换与播放

将动作包放入 `themes/主题名称/theme.nct`，右键奶蛙 →「切换主题」选择。也可通过「导入原版素材」选择包含 `theme.nct` 的文件夹。

录屏主题会提供「选择动作」子菜单。单击动作名开始播放，双击桌宠重复当前动作。开启「循环当前动作」后，动作完成先恢复待机，再短暂停留后继续；拖动、停止或全屏隐藏会中断循环。眼神跟随在待机时生效，播放动作时保留原帧的表情。

程序会记住选择的主题。经典奶蛙的素材位置独立保存，随时可以切回经典主题及完整大笑。新主题的声音只在明确提供匹配音频时使用；当前录屏主题不混入手机通知或其他录音。

## 主题包格式

`.nct` 是一个 ZIP 容器，程序直接按名称读取，解码缓存最多 16 帧，不把所有动作图片常驻内存。结构：

```text
theme.nct
├── manifest.json
├── idle.png
└── actions/
    └── wave/
        ├── 0000.png
        ├── 0001.png
        └── ...
```

所有图片必须是相同画布尺寸的透明 PNG。脚底基准和角色比例应稳定，不能逐帧紧裁剪再随意居中。

```json
{
  "schemaVersion": 1,
  "id": "example",
  "name": "自定义主题",
  "width": 384,
  "height": 448,
  "idle": "idle.png",
  "eyes": [{"x": 160, "y": 80, "width": 16, "height": 20}],
  "belly": {"x": 120, "y": 180, "width": 150, "height": 150},
  "actions": [
    {"id": "wave", "name": "招手", "frames": 90, "fps": 30,
     "prefix": "actions/wave/", "endPose": "idle"}
  ]
}
```

`eyes` 可包含最多四个眼内区域，只在待机时局部跟随；`belly` 控制可点击的肚腹及形变范围。`endPose` 可选 `idle`（动作后过渡回待机）或 `hold`（保留最后一帧）。动作 id 使用小写字母、数字、短横线，且不得重复。

限制：单包最多 256 MB，画布单边最多 1024 像素，总帧数最多 5000，单动作最多 2000 帧，帧率 1～120。加载时验证缺帧、参数、区域边界；读取图片时再检查尺寸。

## 从录屏制作

1. 按时间戳拆帧，检查全片，标出菜单、转场、通知遮挡、角色出画和重复片段。
2. 选择完整的动作段，保持源动作的播放速度；去掉手机界面与背景。
3. 在深浅两种背景上检查白边、翅膀、光环、手指和脚部。浅色身体或翅膀不能直接按纯白像素全部删除。
4. 使用统一的坐标变换和脚底基准，保持动作内部的相对位移，不逐帧自动居中。
5. 校准待机眼部和肚腹，准备动作说明，按上面的结构打包。
6. 运行 `--assets "主题目录" --self-test "测试输出"`，逐帧解码并渲染全部动作；运行 `--render` 查看各动作预览。

命令行可用 `--play wave` 启动后播放指定动作，附加 `--repeat` 开启循环。`--assets` 仍然接收文件夹路径。

只有具有相应公开分发权限的素材才应放进公开仓库或 Release。个人录屏动作包留在本机 `themes` 目录，代码和包格式文档可以单独开源。
