# 主题与动作

## 切换与播放

将动作包放入 `themes/主题名称/theme.nct`，右键奶蛙 →「切换主题」选择。也可通过「导入原版素材」选择包含 `theme.nct` 的文件夹。

录屏主题会提供「选择动作」子菜单。单击动作名开始播放，双击桌宠重复当前动作。开启「循环当前动作」后，动作完成先恢复待机，再短暂停留后继续；拖动、停止或全屏隐藏会中断循环。眼神跟随在待机时生效，播放动作时保留原帧的表情。

程序会记住选择的主题。经典奶蛙的素材位置独立保存，随时可以切回经典主题及完整大笑。新主题的声音只在明确提供匹配音频时使用；声音只随对应动作触发，待机和持续爬行安静。

1.2 的太极奶蛙采用屈膝、伸掌的起势作为待机；原主题目录 `kungfu` 可以保留，只需在包内把名称更新为“太极奶蛙”。爬爬奶蛙单击身体切换持续爬行，右键也有开始/暂停入口。爬行状态默认开启并保存，动作帧与位移一起暂停；拖动、菜单和全屏期间暂停，松手或恢复后继续。爬行限制在当前显示器工作区，保持当前高度，碰边镜像折返。

## 主题包格式

`.nct` 是一个 ZIP 容器，程序直接按名称读取，解码缓存最多 16 帧，不把所有动作图片常驻内存。结构：

```text
theme.nct
├── manifest.json
├── idle.png
└── actions/
    └── wave/
        ├── 0000.png
        ├── 0001.png
        └── ...
```

所有图片必须是相同画布尺寸的透明 PNG。脚底基准和角色比例应稳定，不能逐帧紧裁剪再随意居中。

```json
{
  "schemaVersion": 1,
  "id": "example",
  "name": "自定义主题",
  "width": 384,
  "height": 448,
  "idle": "idle.png",
  "eyes": [{"x": 160, "y": 80, "width": 16, "height": 20}],
  "belly": {"x": 120, "y": 180, "width": 150, "height": 150},
  "actions": [
    {"id": "wave", "name": "招手", "frames": 90, "fps": 30,
     "prefix": "actions/wave/", "endPose": "idle"}
  ]
}
```

`eyes` 可包含最多四个眼内区域，只在待机时局部跟随；`belly` 控制可点击的肚腹及形变范围。`endPose` 可选 `idle`（动作后过渡回待机）或 `hold`（保留最后一帧）。动作 id 使用小写字母、数字、短横线，且不得重复。

1.2 可选字段（省略时与旧包兼容）：

| 字段 | 默认值与作用 |
| --- | --- |
| `colorGamma` | `1`；范围 0.65～1.4，小于 1 提亮中间调 |
| `colorGreen` / `colorBlue` | `1`；范围 0.8～1.2，微调黄色和腹部色彩 |
| `locomotionAction` | 无；设为已有动作 id 后启用持续爬行，建议值 `crawl` |
| `crawlSpeed` | `48`；范围 8～240，100% 大小时每秒移动的像素数 |

本机新版三个录屏包采用 `colorGamma: 0.86`、`colorGreen: 1.035`、`colorBlue: 1.06`。经典包不做校色。校准在解码时统一应用到待机及所有动作帧，保留原透明度并正确处理半透明边缘，不把白色翅膀染黄。

爬行包需提供完整身体、首尾可衔接的步态循环；先去掉录屏画面中的整体位移，再让 `CrawlMotion` 控制桌面位移。循环不使用普通动作的结束停顿。选择其他动作时先停下移动，动作结束后恢复爬行。

限制：单包最多 256 MB，画布单边最多 1024 像素，总帧数最多 5000，单动作最多 2000 帧，帧率 1～120。加载时验证缺帧、参数、区域边界；读取图片时再检查尺寸。

## 从录屏制作

1. 按时间戳拆帧，检查全片，标出菜单、转场、通知遮挡、角色出画和重复片段。
2. 选择完整的动作段，保持源动作的播放速度；去掉手机界面与背景。
3. 在深浅两种背景上检查白边、翅膀、光环、手指和脚部。浅色身体或翅膀不能直接按纯白像素全部删除。
4. 使用统一的坐标变换和脚底基准，保持动作内部的相对位移，不逐帧自动居中。
5. 校准待机眼部和肚腹，准备动作说明，按上面的结构打包。
6. 运行 `--assets "主题目录" --self-test "测试输出"`，逐帧解码并渲染全部动作；运行 `--render` 查看各动作预览。

命令行可用 `--play wave` 启动后播放指定动作，附加 `--repeat` 开启循环。`--assets` 仍然接收文件夹路径。

只有具有相应公开分发权限的素材才应放进公开仓库或 Release。个人录屏动作包留在本机 `themes` 目录，代码和包格式文档可以单独开源。

## 1.4 按头连贯动作与原声

`headReactionAction` 可指定已有动作 id，按头回弹后按原帧率顺序播放整段，不改变菜单选中的动作。省略时沿用旧包的兼容反应。新版爬爬包为连续的「回头看看 → 趴着偷笑」（约 3.27 秒），天使为短暂合掌、停留、收手（约 1.9 秒）。

每个动作可带 `audio: "audio/动作id.wav"`，包内需提供同名 PCM WAV；单段最多 20 MB。省略则安静播放。动作音频和按头反应音频独立加载；切换动作、拖动、再次按压、停止、全屏隐藏和退出都会停止对应声音。右键统一使用「动作声音」开关，首次安装默认关闭。

画面仍使用包内原始尺寸；渲染器在缩放后额外增加四周透明留白，留白可点击穿透。眼部、按头及肚腹的坐标会减去留白后再换算到素材坐标。新增设置 `CanvasVersion` 用于首次升级时补偿旧窗口位置。窗口和显示器边界约束使用完整新尺寸。

录屏里角色若已跑出手机画面，透明窗口无法恢复缺失内容。制作步态必须检查原始录屏左右边缘，并只选身体完整的片段；不能只检查打包后 PNG 的透明角落。

天使动作顺滑修订：`headReactionSeamless: true` 表示片段首末帧已经精确回到待机图像，渲染时直接播放，避免额外叠加一次淡化。此字段默认 false；自测会检查首末帧与待机像素完全一致。按头片段的渲染缓存同时使用动作自身的帧编号，避免与全局时钟错相而漏刷新。

## 1.4.1 完整步态与太极反应

持续爬行的图像和刷新键统一使用 `locomotionAction` 指定动作的帧编号，支持 60 fps，避免固定按 30 fps 跳过中间姿势。循环末尾不复制首帧停留；屏幕位移速度仍由 `crawlSpeed` 给出。`--render` 的爬行演示导出 600 张 60 fps 帧。

本机爬爬包以两段同相位录屏拼合完整身体，重建 53 张正向步态，再补为 106 张 60 fps 帧，循环约 1.77 秒；不使用来回倒放。100% 下前进速度约 84.18 像素/秒。主题宽度增为 448 像素，眼部和肚腹区域同步平移。

新版太极按头反应由录屏中的手脚动作接到镜像经典站姿瞪视，再连续回到起势；转身部分使用局部形变过渡，首末帧与待机一致。太极推掌动作可附带原视频配乐，待机不播放。旧包缺少这些动作时继续使用兼容反应。天使包在修复截断手缘后重新生成 115 张 60 fps 合掌反应。
