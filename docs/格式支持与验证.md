# 文件转换的实际支持范围

当前 1.7.0 沿用 1.6.1 核查修复后的转换器：识别 36 种输入扩展名，提供 223 种转换组合。所需工具见 [转换工具配置](转换工具配置.md)。下表按「输入 → 输出」阅读，原格式不重复转换；能够输入的格式不一定也能作为输出。

| 输入 | 输出 | 组合数 |
| --- | --- | ---: |
| PDF | DOCX、TXT、PNG、JPG | 4 |
| DOCX、DOC、ODT、RTF、TXT | DOCX、DOC、ODT、RTF、TXT、PDF | 25 |
| XLSX、XLS、ODS、CSV | XLSX、XLS、ODS、CSV、PDF | 16 |
| PPTX、PPT、ODP | PPTX、PPT、ODP、PDF、PNG、JPG | 15 |
| PNG、JPG、JPEG、BMP、GIF、TIF、TIFF、静态 WebP | PNG、JPG、BMP、GIF、TIFF、WebP、PDF；GIF 另可转 MP4 | 49 |
| MP4、MOV、MKV、AVI、WebM、M4V、WMV | MP4、MOV、MKV、AVI、WebM、GIF，或提取为 MP3、WAV、FLAC、M4A、OGG | 72 |
| MP3、WAV、FLAC、M4A、AAC、OGG、WMA、AIFF | MP3、WAV、FLAC、M4A、AAC、OGG | 42 |

JPEG/JPG、TIF/TIFF 是输入扩展名别名；不提供同格式重编码入口。视频目标没有 WMV/M4V，音频目标没有 WMA/AIFF，不能把支持输入理解为双向支持。

## 尚未实现

- PDF 直接转 Excel/PPT；扫描 PDF 的 OCR 识别。
- HEIC/HEIF、AVIF、SVG、ICO、PSD、AI、相机 RAW 等图片或设计源文件。
- Markdown、HTML、JSON、XML、EPUB、MOBI 等文档、数据或电子书格式。
- DOCM、XLSM、PPTM 等宏文档；CAD、3D、字体和压缩包转换。
- 动画 WebP。GIF 转 MP4 保留动画；GIF 转静态图/PDF 只保留第一帧。
- 密码输入和解密；加密、受保护或工具无法解析的文件会提示失败。

## 转换后的内容边界

- PDF → DOCX：按原页位置生成可编辑文字框，页面图形嵌入；扫描页仍是图片，表格不自动重建为 Word 表格。字体差异可能影响显示。
- 表格 → CSV：每张工作表分别导出，包含隐藏工作表；保存值，不保存公式、格式或图表。
- XLS 的容量小于 XLSX。超出 65536 行或 256 列的使用范围会停止转换，保留原文件。
- 多页 TIFF：逐页输出；转 PDF 时当前也输出多个单页 PDF，不合并成一个多页 PDF。
- JPEG 和常规视频/音频转换会重新编码，不能保证无损；透明度、色彩、元数据与目标格式有关。视频字幕、附件和封面不转入。
- 提取音频需要原文件存在音轨，转视频/GIF需要存在画面。

## 2026-10-26 核查方式

对全部 223 个菜单组合逐个调用实际转换入口，使用各输入格式的真实样本，检查退出码、输出文件、原文件 SHA-256，并独立解析 ZIP/文档、PDF 页数、工作表数量、中文内容、图片数量/比例以及音视频完整解码。修复后重新测试受影响的图片和表格 65 种组合；额外用 Word/Excel/PowerPoint 重新打开 31 份输出检查中文正文、单元格和幻灯片内容。

另测手机照片 EXIF 方向与镜像、透明 PNG、隐藏表、XLS 行列超限、异常 CSV 引号、不同中文编码、损坏/空文件、动画 WebP 和同名文件/目录。样本通过不代表覆盖了每个编码器、每份超大文件或每一种复杂版面；HDR、特殊媒体流、数字签名和宏等没有据此获得保证。

相关技术资料：[CSV 引号与换行规则](https://www.rfc-editor.org/rfc/rfc4180.html)、[Microsoft 图像旋转接口](https://learn.microsoft.com/en-us/dotnet/api/system.drawing.image.rotateflip)。
