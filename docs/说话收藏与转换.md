# 说话、文字收藏与文件转换

右键奶蛙或托盘，打开「奶蛙说话」「文字收藏」和「文件转换」。这些功能已包含在 1.7.0 公开版中。还可将文件拖到奶蛙身上，选择暂存或转换，详见 [文件口袋](文件口袋.md)。

## 小气泡

按头、戳肚子、拖动和大笑后会用奶白色小气泡回应；动作忙碌时等动作结束再显示。气泡宽约 226 DIP，不抢输入焦点，鼠标停在上面会延长显示。可以点右上角收起。

内置 80 句原创文案。默认闲聊间隔 8–15 分钟，待办每 30 分钟汇报一次；汇报显示未完成数量和最多三项，其余通过「打开待办」查看。添加事项会确认，完成时会夸夸。语录是文字气泡，原动作声音仍由「动作声音」开关控制。

在「奶蛙说话 → 说话设置」调整互动回应、待办回应、闲聊频率、固定提醒时刻、语录口味、停留秒数和安静时段。可单独关闭闲聊或自动汇报。「安静1小时」会保存到本机；待办气泡也可点「稍后15分」。全屏期间隐藏，恢复后不集中弹出积压提示。

## 文字收藏

「新建」后填写正文并保存，标题可以留空；左侧搜索标题和正文。选中收藏后可编辑、保存或「复制文字」，再到其他应用按 Ctrl+V。

「收藏剪贴板文字」只在点击时读取剪贴板，不后台监听。删除和保存支持撤销上一步；撤销记录只在本次运行保留。关闭窗口会保留当前草稿，退出整个程序前请保存。最多 200 条，每条正文最多 20000 个字符。

## 文件转换

选择或拖入文件，选择目标格式和保存目录，再点「开始转换」。批量文件须有共同目标格式；不同种类可分批处理。「查看结果」定位选中项目。

| 输入 | 可用目标 |
| --- | --- |
| PDF | Word DOCX、TXT、PNG、JPG |
| Word、DOC、RTF、ODT、TXT | DOCX、PDF、DOC、RTF、TXT、ODT |
| Excel、XLS、ODS、CSV | XLSX、PDF、CSV、XLS、ODS |
| PowerPoint、PPT、ODP | PPTX、PDF、PNG、JPG、PPT、ODP |
| 常用图片、WebP、TIFF | PNG、JPG、PDF、WebP、BMP、TIFF、GIF |
| 常用视频 | MP4、MKV、MOV、WebM、AVI、GIF，或提取为常用音频 |
| 常用音频 | MP3、WAV、FLAC、M4A、AAC、OGG |

同格式不重复转换；动画 GIF 还可转 MP4。界面只列实际支持的组合。

当前共识别 36 种输入扩展名、223 种组合，并非任意格式互转；完整方向清单与限制见 [格式支持与验证](格式支持与验证.md)。WebP 当前仅支持静态图；加密文档没有密码输入入口。超出 XLS 容量时会停止并提示保留 XLSX/ODS，避免截断。

原文件先复制到独立临时目录，转换前后核对 SHA-256。结果重新读取、解析或解码后才另存；同名结果自动编号，不覆盖原件和旧结果。取消或失败时清理本次任务创建的进程和临时文件。损坏或无法解析的输入会报告失败。

PDF 转 Word 按原页位置生成可编辑文字框，并把页面图形嵌入 DOCX，再由 Word 重新打开检查页数。表格线和插图保留为页面图形，不自动重建成原生 Word 表格。复杂字体和文字框仍可能有排版差异；扫描页保留为图片，需要 OCR 才能编辑图中文字。请打开结果确认版面适合用途。

多工作表转 CSV 时每张表分别输出，只保存值；公式、图表和样式不进入 CSV。CSV 导入按文字保留编号前导零、引号和单元格内换行。幻灯片导出图片保留原长宽比，并导出全部页面。多页 TIFF 分页输出；GIF 转静态图片或 PDF 仅保留第一帧。视频保留主画面和音轨，字幕和封面不转入；GIF 没有声音。

办公格式需要已安装且完成初始化的 Microsoft Office；PDF 使用 Poppler，音视频和 WebP 使用 FFmpeg。公开包不捆绑这些工具，可在「转换工具」指定路径；程序也支持从安装目录 tools 或 PATH 查找。全部转换在本机完成，详见 [转换工具配置](转换工具配置.md)。

## 数据与升级

数据默认位于 `%LOCALAPPDATA%\NaiwaCompanion`，也可通过 `storage.local.json` 指定目录：`todos.json` 为待办，`snippets.json` 为收藏，`speech.json` 为说话设置，`conversion-tools.json` 为工具路径。JSON 保存采用替换和备份；较新版本或异常数据会保护原文件并显示提示。

升级保留原有经典素材、主题包、原声和 settings.json。需要回退时先退出程序，再使用本次安装记录中的备份程序；新增收藏和设置请另存备份。
