# 桌面小待办 · 设计与使用说明

1.5.0 新增。它是一张奶蛙旁边的小卡片，用来记下眼前要做的事。卡片可以独立拖动、关闭和重新打开，不跟随奶蛙爬行。此功能已包含在 1.7.0 公开版中。

## 入口和布局

- 右键奶蛙或托盘，选择「小待办 · N 件待完成」。再次选择会唤回已有卡片，不重复开窗口。
- 卡片首次出现在奶蛙旁边，之后记住用户放置的位置。窗口离开当前屏幕时会移回可见工作区；支持副屏负坐标。
- 上方显示标题和待完成数量，中间是输入框与可滚动列表，下方是保存反馈、撤销和更多操作。
- 使用浅奶白底色、绿色操作按钮，跟随系统 DPI 放大。长事项显示两行摘要，悬停可看完整内容。
- 默认空白，不向真实清单填入示例事项。

## 日常操作

| 想做什么 | 操作与结果 |
| --- | --- |
| 添加 | 输入后按 Enter，或点击「添加」；保存成功后清空输入框 |
| 完成 | 勾选事项，移入「已完成」；卡片显示一句轻提示 |
| 查看已完成 | 点击「已完成 N · 展开」；初始默认折叠 |
| 恢复事项 | 展开后取消勾选，或在事项右侧的「⋯」中选择「放回待办」 |
| 修改 | 双击事项文字，或在该行「⋯」中选择「修改内容」；上方输入框切换成修改模式，按 Enter 或点「保存」 |
| 取消修改 | 按 Esc 或点击「取消修改」；原事项保持不变，恢复先前尚未添加的输入草稿 |
| 删除 | 在事项右侧「⋯」中选择「删除」 |
| 撤销 | 点击左下角「撤销」，恢复本次运行中最近一次添加、修改、完成、恢复、删除或清空操作 |
| 清理 | 右下角「⋯」→「清空已完成（可撤销）」 |
| 收起 | 点击窗口右上角关闭；奶蛙继续运行，重新打开后内容仍在 |

未完成按添加顺序排列，已完成集中在下面。不强制每天清空，不限制只能记三条；每条最多 120 个 UTF-16 字符，最多保留 200 条（含已完成）。同名事项允许重复。撤销仅保留一步，在下一次内容变更时替换，退出程序后不保留。

## 保存与保护

- 每次内容变更立即写入 `%LOCALAPPDATA%\NaiwaCompanion\todos.json`。安装目录换了，清单仍保留在同一个 Windows 用户目录。
- 内容仅保存在本机，不上传、不要求账户。它是普通 JSON 文件；可以从右下角「⋯」打开数据文件夹后自行备份。
- 先写临时文件并刷新到磁盘，再原子替换正式文件；保留上一份成功保存的 `todos.json.bak`。
- 保存失败会在卡片下方说明，保留原有清单和输入，不显示虚假的保存成功。
- 正式文件损坏时尝试上一次备份，保留异常文件并明确提示恢复；备份可能不含最后一次变更。两份均不可读时停止写入，保留原文件。
- 来自更新版本的文件也停止写入，避免旧程序回退覆盖新格式。
- 重启程序时恢复上次展开的卡片、位置和已完成折叠状态；启动恢复时不抢键盘焦点。未按添加或保存的输入属于草稿，只在当前运行期间保留。

## 与奶蛙的配合

小待办使用能正常获得键盘焦点的独立窗口。奶蛙本体仍然不抢焦点，保留按头、拖动、双击、笑倒、声音和切换主题行为。完成事项仅在卡片里给出反馈，不打断奶蛙动作。

「总在最上面」同时控制奶蛙和卡片。启用「全屏时自动隐藏」时，卡片随奶蛙隐藏，退出全屏后只恢复此前展开的卡片；手动收起的卡片不会被自动打开。隐藏期间的新增或修改草稿保留。

待办卡片专注于随手记录与完成；说话设置可配置定时汇报与安静时段，但没有每项任务的到期日期、重复事项、跨设备同步或任务管理账户。

## 开发与验证

- `src/TodoStore.cs`：条目、原子保存、备份恢复、单步撤销与视图状态。
- `src/TodoForm.cs`：独立卡片、输入和修改、事项操作、折叠与全屏生命周期。
- `src/PetForm.cs`：右键与托盘入口、置顶和隐藏联动、退出保存。
- `src/TodoTests.cs`：独立临时目录中的持久化、写入失败、损坏恢复、撤销和原生窗口行为测试，不读取真实清单。
- `--show-todos`：打开运行中桌宠的小待办；没有实例时正常启动后打开。`--probe` 增加 `TodoVisible`。

运行 `scripts/Build.ps1` 后执行 `--self-test`。自测还输出 `todo-empty.png`、`todo-filled.png`、`todo-completed.png` 供检查真实 WinForms 布局；示例只存在于测试目录。
