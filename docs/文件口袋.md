# 文件口袋

把文件或文件夹拖到奶蛙的可见身体上，会弹出操作窗口：

- **暂存到文件口袋**：复制保存，原位置的文件保留；同名项目自动另取名字。
- **转换格式**：把支持转换的文件交给现有转换窗口，选择格式后才开始转换。多个文件没有共同目标格式时，请分批处理。
- **查看口袋**：显示暂存目录的实际内容，包括从资源管理器手工放进去的项目。

也可右键奶蛙或托盘图标，点击「文件口袋 · 查看暂存文件」。列表中显示名称、类型、大小和修改时间。双击或点击「定位所选项目」会在资源管理器中选中项目；点击「打开文件夹」可浏览、移动或自行删除内容。「转换所选文件」可继续处理暂存文件。关闭口袋窗口不会删除文件。

文件夹可以整套复制，保留子目录、空目录和空文件。暂不接收整个磁盘、目录联接或符号链接，也不会把口袋自身及其上级目录递归放入口袋。无法读取或复制过程中增删了内容的项目会说明原因；其他成功项目保留。暂存可取消，未完成的项目不会出现在正常文件列表中。异常退出遗留的 `.naiwa-pending-*` 目录属于未完成副本，列表不会将其显示为已保存项目。

暂存逐文件校验 SHA-256，复制与校验在后台执行。没有上传、定时清理或自动移动原文件。全屏时口袋及选择窗口随奶蛙隐藏，退出全屏后恢复。

## 存储位置与 D 盘配置

普通安装默认使用 `%LOCALAPPDATA%\NaiwaCompanion`，口袋和转换结果分别位于其「文件口袋」「转换结果」子目录。程序本身可以解压到自己选择的磁盘。

如需将所有数据放到 D 盘，先退出奶蛙并备份原数据，把原数据复制到新目录，核对文件数量和内容；然后参考 `examples/storage.example.json`，在程序旁新建 `storage.local.json`：

```json
{
  "DataDirectory": "D:\\NaiwaData\\数据",
  "PocketDirectory": "D:\\NaiwaData\\文件口袋",
  "ConversionDirectory": "D:\\NaiwaData\\转换结果"
}
```

重新启动后检查待办和设置是否恢复，再决定如何保留旧数据。只更改配置不会自动迁移旧内容；切换存储目录时也需另行迁移已有口袋和转换结果。升级程序时保留自己的 `storage.local.json`。

程序旁的 `storage.local.json` 可配置 `DataDirectory`、`PocketDirectory`、`ConversionDirectory`，支持绝对路径或相对程序目录的路径。此文件仅影响本机，不提交到公开源码。未配置的普通安装使用本机应用数据目录。显式配置无效或 D 盘不可写时会报错，不会偷偷改存到 C 盘。需要更换配置时先退出奶蛙，备份并迁移现有内容后再修改配置。

命令行 `NaiwaCompanion.exe --show-pocket` 可唤回口袋窗口。
