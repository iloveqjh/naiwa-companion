# 文件转换需要哪些工具

桌宠互动、待办、说话气泡、文字收藏和文件口袋不依赖下面的工具。程序会检查每批转换所需的工具，缺少时说明原因；不会显示转换成功。

| 功能 | 所需工具 |
| --- | --- |
| PNG、JPG、BMP、GIF、TIFF 等常规静态图片互转 | Windows / .NET Framework 内置支持 |
| 办公文档、表格、幻灯片转换及相应输出校验 | 对应的 Microsoft Word、Excel、PowerPoint，已安装并完成首次初始化 |
| 音视频、静态 WebP、GIF 转 MP4 | FFmpeg，包含所需编码器 |
| PDF 页数校验、提取文字、导出图片、辅助 PDF 转 Word | Poppler 的 `pdfinfo.exe`、`pdftoppm.exe`、`pdftotext.exe`，以及这些工具自身所需 DLL |
| PDF 转 Word DOCX | Poppler 与 Microsoft Word |

并非任意两种格式都能转换。部分目标会同时需要多个工具，例如办公文件转 PDF 后还需要 Poppler 校验。以界面针对当前文件显示的检查结果为准，完整方向见 [格式支持与验证](格式支持与验证.md)。

## 配置步骤

1. 从软件官方渠道或可信发行渠道安装所需组件。FFmpeg 项目入口：[下载说明](https://ffmpeg.org/download.html)；Poppler 项目入口：[官方网站](https://poppler.freedesktop.org/)。这些项目与本桌宠分别维护。
2. 右键奶蛙 →「文件转换」→「转换工具」。
3. 选择 `ffmpeg.exe`，或选择含三个 PDF 命令及其依赖的完整文件夹，保存。
4. 回到转换窗口，先用一份副本检查输出格式和内容，再处理正式文件。

也可自行把工具放入程序目录的 `tools/ffmpeg/ffmpeg.exe`、`tools/poppler/pdfinfo.exe` 等位置，或将工具加入 PATH。程序不会自动下载或安装转换组件，不包含 Office 授权。公开安装包不捆绑第三方二进制；这些工具各自的许可和分发要求由对应发行者说明。

CSV 导出会保留值，格式与公式不会进入 CSV；扫描 PDF 没有 OCR；动画 WebP 暂不支持。转换失败时原文件保留，结果成功另存后仍应检查版面和内容是否符合用途。
