# 主题修订记录与最终参数

本记录描述 2026-10-22 完成的本机参考主题，随 1.4.1 的公开说明同步。程序支持这些字段和行为；角色帧与录屏原声需要用户自行准备，程序 ZIP 不附带个人主题包。机器可读参数见 [reference-theme-revision.json](../examples/reference-theme-revision.json)。

## 太极：直接换站姿，注视约 1.2 秒

按头松手先完成已有的 Q 弹回摆，然后快速切到镜像经典站姿，注视片刻，快速回到太极起势。最终反应共 **94 帧、60 fps、约 1.57 秒**，其中完整注视停留 **72 帧、1.2 秒**。此处时长只计算主题反应，不包含用户按住头部的时间与此前回弹。

- 第 0 帧与第 93 帧均与太极 `idle.png` 完全相同。
- 第 1～10 帧进入眼神；第 11～82 帧保持注视；第 83～92 帧回正。
- 保留完整角色图像，直接切换完整站姿。没有额外的合掌、挥手、并腿铺垫，也不使用会拉扯肚皮的中间形变。
- 镜像经典站姿的方向与太极待机相符；颜色以经典素材为同一基准。
- 太极推掌菜单动作保留 352 帧、30 fps、约 11.73 秒，绑定匹配原视频配乐。注视反应没有单独加音乐。

如需调整同类包的停留，仓库提供仅使用 Python 标准库的作者工具：

```powershell
python scripts/Set-ThemeGazeHold.py --input theme.nct --output theme-new.nct --hold-seconds 1.2
```

该工具适用于本记录的「首帧待机、10 帧进入、注视停留、10 帧退出、末帧待机」布局。它保留图像字节、颜色和其他动作，不覆盖原包；不对带动作音频的反应直接改时长。修改后先自测并渲染，再自行替换使用中的包。

## 天使：手部完整，连续合掌再收手

补全原录屏边缘缺失的左侧手缘，涉及 170 张吟唱与祈祷原帧。按头反应重新整理为 **115 帧、60 fps、约 1.92 秒** 的合掌、收手、复原，首末帧与待机一致。神圣吟唱、独立祈祷菜单动作及各自原声保留。

素材检查要同时区分两种缺失：原视频中已经出画的手指，以及透明窗口过窄造成的裁切。增加窗口边距不能恢复已经不存在的原帧内容。

## 爬爬：完整正向步态，回头再偷笑

- 将两段同相位录屏中的完整前肢、后肢拼合，去掉整体前进位移，重建伸爪、撑地和后腿蹬伸的 53 张原始正向姿势。
- 补为 **106 帧、60 fps** 的循环，约 1.77 秒；包含循环交界的中间姿势。步态不来回倒放。
- 100% 大小的桌面速度为 **84.177 像素/秒**；随用户选择的显示大小同比缩放，匹配录屏步幅。
- 画布为 **448 × 448**，原有待机、动作、眼部及肚腹坐标同步平移，容纳完整身体。
- 按头反应为 **98 帧、30 fps、约 3.27 秒** 的「回头看看 → 趴着偷笑」，保留对应原声。
- 按压、动作、菜单、拖动和全屏时暂停移动；结束后按原开关状态继续，碰到当前屏幕工作区边缘镜像折返。

## 四主题统一颜色

以经典奶蛙原素材为黄色基准，校准三个录屏主题的色相、饱和度与亮度，并保留阴影、肚皮、深色手脚、眼睛与白色翅膀。黄色皮肤采样中位色相为：经典约 40.385°、太极 40.351°、天使 40.400°、爬爬 40.491°。这些是本组素材的采样值，不是所有角色的通用固定颜色。

本组修订将校色烘焙进 PNG，因此包内 `colorGamma`、`colorGreen`、`colorBlue` 均为 **1**。旧包的 0.86 / 1.035 / 1.06 参数不应再次用于已校色图像，避免重复变色。所有既有图像的 alpha 通道逐像素保留，音频逐字节保留。

不同姿势的光照、高光和阴影仍有自然差异；统一的是皮肤黄色基准，不能把所有表面刷成同一色块。

## 程序与主题包分别验证

程序支持按主题实际帧率刷新，60 fps 爬行动作不会再固定按 30 fps 判断缓存键。窗口在实际角色尺寸外增加透明留白，命中坐标同步补偿，空白仍可点击穿透。

每次修改主题后运行：

```powershell
.\NaiwaCompanion.exe --assets "主题目录" --self-test "检查输出"
.\NaiwaCompanion.exe --assets "主题目录" --render-press "按压预览输出"
```

同时检查完整身体、手指、脚底、深浅背景、首末帧和声音起止。帧数、时长与边缘检查不能代替最终观看。历史版本中的 5.47 秒多步骤太极反应、0.42 秒快速反应和 2 秒反应已被上述最终编排替代。
