## 本人的完整迁移备份

仓库作者的 [个人私有备份](https://github.com/iloveqjh/naiwa-companion-personal-backup) 保存三个完整主题、当前设置与待办、不同内容的历史设置、经典素材以及制作脚本。访问需要自己的GitHub账号和仓库权限。

在新电脑克隆程序仓库和私有备份，准备好程序目录，关闭该目录中的奶娃进程后运行：

```powershell
.\scripts\Restore-PersonalBackup.ps1 -BackupRoot "私有备份目录" -ProgramDirectory "新电脑程序目录"
```

需要恢复设置、待办等本地信息时，显式指定新机实际数据目录：

```powershell
.\scripts\Restore-PersonalBackup.ps1 -BackupRoot "私有备份目录" -ProgramDirectory "新电脑程序目录" -RestorePersonalData -DataDirectory "新电脑数据目录"
```

脚本先验证全部待复制文件的SHA-256，再复制；同名旧文件先备份。完成后会写入 `migration-restored.json`。原目录仍在旧电脑，迁移验收前保留。
